# Research notes

Each note lives in `notes/<study>/<date>-<slug>/` with `note.md` and the `facts.json` snapshot it was written from. See [docs/writing-notes.md](../docs/writing-notes.md) for how notes are written and [docs/note-style.md](../docs/note-style.md) for the house style. CI runs `lpresearch check-notes` on every pull request.
